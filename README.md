# בדיקה מהירה - אפליקציה עצמאית לבדיקה קולית של אביזרי הרמה

אפליקציית ווב (PWA) ל-Chrome באנדרואיד. ללא שרת: הקובץ נפתח מהטלפון, הסשן נשמר במכשיר, והתוצאות מיוצאות כקבצים.

```
קובץ ריכוז (xlsx)  →  בחירת אתר  →  בדיקה קולית בשטח  →  ייצוא:
                                                          • ריכוז מעודכן (xlsx) - אותו קובץ + עמודות הבדיקה + שורות לפריטים חדשים
                                                          • נבדקו היום (xlsx)  - שורה לכל פריט שנבדק, עם הנתונים לתסקיר
                                                          • JSON לתסקירים       - קבוצות סוג × מיקום, שורות לפי תיאור, כמות, עומס, מספרים, ליקויים
```

## התקנה והפעלה

```bash
npm install
npm run dev        # פיתוח: http://<ip-של-המחשב>:5173 (לטלפון באותה רשת)
npm run build      # תיקיית dist/ - קבצים סטטיים
npm test           # בדיקות: פרסר, מנוע, סבב אקסל מלא על קובץ ריכוז (אם קיים בנתיב שבבדיקה)
```

**בשטח נדרש HTTPS** (המיקרופון לא זמין ב-http רגיל, למעט localhost). אפשרויות פשוטות להעלות את `dist/`:
Firebase Hosting (`firebase deploy` - כבר יש לכם פרויקט Firebase), GitHub Pages, או Netlify. אחרי הפתיחה הראשונה
בכרום: תפריט → "הוסף למסך הבית" - האפליקציה נפתחת כאפליקציה ועובדת גם ללא רשת (חוץ מהזיהוי הקולי עצמו).

## קובץ הריכוז

הגיליון הראשון שמכיל עמודת "מס' סידורי" נקרא כטבלת הפריטים. עמודות שמזוהות לפי הכותרת:
אתר · סוג מתקן / אביזר · תיאור (כפי שבתסקיר) · מס' סידורי / פנימי · תאריך בדיקה אחרונה · ממצא בבדיקה · קבוצה / מחזיק · מס' תסקיר · מקור.
עמודות אחרות נשמרות כמו שהן.

בייצוא נוספות (או מתעדכנות) העמודות: תאריך בדיקה נוכחית · תוצאה נוכחית · ליקויים / הערה נוכחית · מיקום נוכחי ·
מיקום קודם (אם הועבר) · עומס עבודה (טון) · פריט חדש · ביטחון זיהוי. פריט חדש = שורה חדשה באתר, מקור "בדיקה בשטח".
הקובץ נכתב כערכים (הנוסחאות והעיצוב של הקובץ המקורי לא נשמרים - מומלץ לשמור את המקור).

**גיליון "קטלוג"** (נוצר בייצוא, ניתן לעריכה באקסל ונטען בפעם הבאה): סוג · תיאור · עומס (טון) · כינויים קוליים (מופרדים ב-|).
ניסוחים שונים של אותו אביזר ("שאקל במבנה Ω 7/8", "שקל הרמה ... 6.5 טון, גודל 7/8") מאוחדים אוטומטית לרשומה אחת;
כינויים ברירת מחדל נגזרים מהתיאור ("רצועה עגולה 4 מטר", "שאקל שבע שמיניות", "מענב 2 ענפים 2 מטר") ואפשר לערוך אותם
גם בתוך האפליקציה (גלגל השיניים במסך הבדיקה). שם מדויק לרצועות לפי צבע ("רצועה ירוקה 4 מטר") מוסיפים שם.

## מה אומרים בשטח

| אומרים | קורה |
|---|---|
| `מקום מחסן כלים` / `קבוצה דנה רוני` | מיקום פעיל (מהרשימה בקובץ; לא מוכר → "מיקום חדש?") |
| `רצועה ארבע מטר` / `שאקל שבע שמיניות` | סוג פעיל (עמום → "איזה? 1/2/3" ואומרים מספר) |
| `אחת אפס ארבע חמש` | 4 ספרות אחרונות בסוג הפעיל → תקין |
| `1045 פסול חתך` / `1045 תקין תווית דהויה` | פסול + ליקוי / תקין עם הערה לסעיף הליקויים |
| שני פריטים עם אותן 4 ספרות | "מה הספרה לפני?" |
| מספר שלא ברשימה | "מספר מלא?" → `אס פי אפס אפס שבע שבע שמונה אפס` → פריט חדש בסוג ובמיקום הפעילים |
| `חדש קי חמש אפס אפס אחת חמש שמונה פסול` | פריט חדש במשפט אחד |
| מספר שקיים בסוג אחר | "להעביר לסוג הפעיל?" כן / לא (= חדש) |
| פריט שנמצא במיקום אחר | המיקום מתעדכן אוטומטית; מופיע ב"מעברים" |
| `בטל` / `חזור` / `מצב` | ביטול / הקראה / מונים |

## מבנה הקוד

```
src/

  screens/HomeScreen.jsx       פתיחת קובץ / המשך סשן שמור
  screens/SiteScreen.jsx       בחירת אתר ושם לקוח
  screens/CatalogScreen.jsx    עריכת כינויים ועומס
  screens/ExportScreen.jsx     שלושת הייצואים
  components/RapidInspectionScreen.jsx   מסך הבדיקה הקולית
  hooks/useRapidInspection.js, useSpeechRecognition.js
  utils/voiceParser.js         הדקדוק הקולי (טהור, נבדק ב-node)
  utils/rapidInspectionEngine.js  מנוע המצב (טהור)
  utils/audioFeedback.js       צפצופים והקראה
  services/excelService.js     קריאת הריכוז, קטלוג, סשן, ייצוא (xlsx / JSON)
  services/sessionStore.js     IndexedDB + הורדת קבצים
tests/                         voiceParser · rapidInspectionEngine · excelService (סבב מלא) · e2e (Playwright, אופציונלי)
```

## מבנה ה-JSON לתסקירים

```json
{
  "clientName": "חברת החשמל", "site": "קישון", "date": "17/11/2026",
  "counts": { "total": 3161, "ok": 0, "fail": 1, "notFound": 0, "pending": 3160, "new": 1 },
  "groups": [
    { "type": "שאקל", "location": "מחסן כלים",
      "lines": [ { "description": "שאקל הרמה במבנה Ωגודל \"7/8", "swl": 6.5, "quantity": 3, "serials": ["10498", "24337"], "failedSerials": ["Q1234"] } ],
      "defects": [ { "serial": "Q1234", "status": "fail", "text": "חתך / קרע", "isNew": true } ] }
  ],
  "notFound": [ { "serial": "...", "description": "...", "location": "..." } ],
  "moved": [ { "serial": "...", "from": "דנה רוני", "to": "מחסן כלים" } ]
}
```
כל `group` = תסקיר אחד (סוג × מיקום); `lines` = שורות הטבלה (תיאור, כמות, עומס, רשימת מספרים); `failedSerials` לתסקיר הפסולים.
